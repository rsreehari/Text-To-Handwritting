# Text to Handwriting

A tool that converts digital text into handwriting-like images. Perfect for creating more natural-looking notes or assignments.

## Features

- Convert text to handwriting with various font styles
- Customizable letter and word spacing
- Adjustable page margins and line height
- Support for custom fonts
- Dark mode support
- Export to image or PDF

## Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for loading fonts and dependencies)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rsreehari/text-to-handwriting.git
   cd text-to-handwriting
   ```

2. Open `index.html` in your web browser.

## Usage

1. Type or paste your text into the input area
2. Customize the appearance using the options panel:
   - Select a handwriting font
   - Adjust font size, letter spacing, and word spacing
   - Customize page margins and line height
   - Change ink color
3. Click "Generate Image" to create your handwritten document
4. Download the result as an image or PDF

## Customization

### Adding Custom Fonts

1. Click "Upload Font" and select a TTF or OTF font file
2. The font will be available in the font selection dropdown

### Page Layout

- Toggle page margins and line guides using the checkboxes
- Adjust top padding to control the starting position of your text
